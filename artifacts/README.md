# Model artifacts

Binary models are excluded from Git. Use this directory only for local copies
or publish models as versioned repository release assets.

Every artifact must have an entry in `manifest.json`. A manifest entry does not
mean that the artifact is approved for Android deployment.

Suggested release names:

```text
skincare-multimodal-256-v0.1.0.keras
skincare-multimodal-256-v0.1.0.tflite
SHA256SUMS
```
